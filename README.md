# 🏃 WOYuk! — Obah Bareng, Konsisten Bendino

Aplikasi pencatat aktivitas olahraga modern (lari, jalan, sepeda) dengan pelacakan GPS realtime, sistem streak harian, dan visualisasi rute. Dibangun dengan Laravel dan Tailwind CSS.

## 🚀 Fitur Utama
- **Tracking GPS Realtime**: Pencatatan rute presisi dengan peta interaktif Leaflet JS.
- **Daily Streak System**: Jaga konsistensi olahraga harian.
- **Target Jarak & Kalori**: Pantau akumulasi metrik harian.
- **Arsip & Rekap Rute**: Riwayat aktivitas dengan filter dan peta rekap.

## 🛠️ Teknologi yang Digunakan
- **Backend**: Laravel (PHP)
- **Frontend**: Tailwind CSS, Alpine.js, AOS (Animate on Scroll)
- **Database**: MySQL
- **Peta**: Leaflet JS
